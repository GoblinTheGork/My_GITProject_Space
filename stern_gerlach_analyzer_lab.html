Atom source

Source model

Silver atoms are treated as spin-½ particles. Each analyzer measures spin along its chosen axis and separates atoms into + or − output channels. For a spin eigenstate, the probability of + along an axis at angle θ is \(P(+)=\cos^2(θ/2)\).

Analyzer chain

Use one, two, or three analyzers. Each later analyzer can receive the + or − output of the previous analyzer.

Measurement results

Run the experiment to see the number and fraction of atoms in each output channel.

How to read this

An analyzer oriented along z measures spin along z. Rotating it changes the probabilities of the two possible outcomes.

Quantum probability
P(+ at next analyzer) = cos²(Δθ / 2)

Model note: this is a teaching simulation. Each atom is sampled probabilistically; finite atom counts can produce small statistical deviations from ideal probabilities. The diagram is schematic, not to scale.
